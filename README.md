# Sorting App

Консольное приложение на Java для работы с коллекцией студентов, поддерживающее загрузку, сортировку, сохранение и анализ данных.

## Возможности

- Заполнение коллекции студентов:
    - загрузка из JSON-файла;
    - генерация случайных данных;
    - ручной ввод данных.

- Сортировка студентов:
    - по номеру группы;
    - по среднему баллу;
    - по номеру зачётной книжки;
    - по возрастанию и убыванию.

- Поддерживаемые алгоритмы сортировки:
    - Bubble Sort;
    - Selection Sort;
    - EvenOddFilter.

- Запись результата в файл в формате JSON.

- Подсчёт количества вхождений заданного студента в коллекции.


## Технологии

- Java
- Generics
- Собственная реализация коллекции `CustomCollection`
- Паттерн Strategy для алгоритмов сортировки
- Работа с JSON
